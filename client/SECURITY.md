# Security Policy

## Supported Versions

We recommend always running the latest release of Storeify Frontend.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0.0 | No                 |

---

## Reporting a Vulnerability

If you discover a security vulnerability within Storeify Frontend, please follow responsible disclosure practices:

1. **Do not create a public issue** on GitHub.
2. Submit your findings privately via email to the maintainers or via GitHub Private Vulnerability Reporting if enabled.
3. Provide a detailed summary including:
   * Description of the vulnerability.
   * Steps to reproduce the issue or proof-of-concept.
   * Potential impact and affected components.
   * Suggested remediation, if known.

### Response Timeline
* **Acknowledgement:** Within 48 hours of initial report.
* **Assessment & Fix:** Maintainers will investigate and provide regular updates until a patch is issued.
* **Public Disclosure:** Following release of a patched version or coordinate with the reporter.

Thank you for helping keep Storeify safe and secure for everyone.
